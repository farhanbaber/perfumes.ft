## 🎬 Animation Sequence Examples

### Hero Section Entry
```
1. Tagline: Fade in + slide up (200ms)
2. Heading: Fade in + slide up (400ms)
3. Description: Fade in + slide up (600ms)
4. Buttons: Fade in + slide up (800ms)
5. Background: Pulsing gradient (infinite)
6. Scroll indicator: Bouncing animation (infinite)
```

### Product Showcase Hover
```
On Hover:
1. Container: 3D tilt effect (rotateY: 5°, rotateX: -5°)
2. Shadow: Expand and intensify
3. Border: Fade to accent color
4. Product floating: Slight Y-axis movement
```

### Testimonial Rotation
```
Every 6 seconds:
1. Fade out (300ms)
2. Slide transition (200ms)
3. Fade in (300ms)
4. Content update
5. Repeat
```

## 🚀 Quick Reference - Common Tasks

### Change Product Name
```
File: src/components/home/FeaturedShowcase.tsx
Line: ~70
Change: "Essence Noir" → "Your Product Name"
```

### Update Fragrance Notes
```
File: src/components/product/FragranceArchitecture.tsx
Lines: 10-40
Change: notes array with your ingredients
```

### Modify Contact Email
```
File: src/components/contact/SocialConnect.tsx
Line: ~35
Change: email address in href
```

### Change Accent Color
```
File: tailwind.config.js
Lines: 8-9
Change: 'accent': '#d4a574' to your color
```
